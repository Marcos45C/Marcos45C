## 🚀 Proyectos y áreas de desarrollo

Me gusta aplicar los conocimientos adquiridos en proyectos prácticos. Algunos de los trabajos en los que estoy involucrado son:

### 🛒 Sistemas comerciales y lectura de códigos de barras
Desarrollo de soluciones para entornos comerciales, incluyendo integración de lectores de códigos de barras USB, procesamiento de productos y almacenamiento de información mediante Supabase.

### 🎛️ Stream Deck con ESP32
Desarrollo de una aplicación de escritorio en **C#/.NET y Avalonia**, orientada a controlar un dispositivo ESP32. El proyecto contempla perfiles, botones configurables, accesos directos, macros y comunicación mediante USB o Bluetooth.

### 🌬️ Monitor ambiental con ESP32
Experimentación con sensores electrónicos, incluyendo el módulo MH-Z19C para medición de concentración de CO₂. Desarrollo de firmware con umbrales de advertencia y alarma, además de respuestas visuales y escalonadas.

### 🖨️ Catálogo de diseños e impresión 3D
Desarrollo de un sitio web estático con **Astro**, preparado para desplegarse mediante Cloudflare. Orientado a mostrar diseños, modelos y productos de impresión 3D.

### 📱 Aplicaciones web con React y Supabase
Desarrollo de aplicaciones web con autenticación, persistencia de datos, notificaciones programadas y generación de informes. Trabajo con React, TypeScript, Tailwind CSS y servicios de Supabase.
